# CAF Quick View

Charleston Amish Furniture sales by user, including split sales.

The page is published from this repo. The OrderTrac sign-in is a GitHub secret. The published numbers are encrypted with the page password.

On a Windows PC, download the `windows` folder and double-click `Open Widget.vbs`. That opens a small always-on-top window in Edge. The password is the same one used on the web page.
